
# DigiBitWallet

A modern, fake cryptocurrency wallet app that displays real-time live prices of the top 25 cryptocurrencies along with their blockchain networks.

## Features

✨ **Real-time Crypto Prices**: Live price updates from CoinGecko API  
💼 **Portfolio Management**: Track your fake crypto holdings  
📊 **Market Overview**: Browse top 25 cryptocurrencies  
🌐 **Network Information**: See which blockchain each coin uses  
💰 **Balance Tracking**: Monitor your total portfolio value  
📈 **24h Change**: View price movements over 24 hours  
🎨 **Modern UI**: Beautiful gradient design with smooth animations  
📱 **Responsive Design**: Works on desktop and mobile devices
